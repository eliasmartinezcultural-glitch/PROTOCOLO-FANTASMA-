# PROTOCOLO FANTASMA

**Centro de Investigación, Análisis e Inteligencia Territorial de San Patricio del Chañar**  
Desarrollado por Elías Martínez · Ocarina Producciones.

## Versión 0.7 — Observatorio político y social

PROTOCOLO FANTASMA deja de ser solamente una mesa documental y pasa a organizar un centro de análisis territorial sobre la vida pública de San Patricio del Chañar: gestión municipal, decisiones, obras, servicios, actores, instituciones, declaraciones públicas, información y escenarios electorales.

### Módulos de trabajo

- **Centro de análisis:** mapa operativo para entrar por tema.
- **Archivo / expedientes:** preguntas de investigación y temas que requieren seguimiento.
- **Actores:** personas e instituciones en sus roles públicos documentados.
- **Gestión pública:** decisiones, obras, servicios e indicadores públicos.
- **Escenario electoral:** candidaturas, propuestas y declaraciones públicas disponibles.
- **Fuentes:** documentos, enlaces, autoría, fechas y fragmentos.
- **Hipótesis y contraste:** separar hechos, declaraciones, análisis e interrogantes.
- **Seguimiento:** próximos pasos de investigación.
- **Cronología:** secuencia de eventos y documentos.

### Método

1. Registrar qué se afirma y quién lo afirma.
2. Conservar fuente, fecha, autoría o procedencia.
3. Separar hechos documentados, declaraciones, hipótesis y percepciones.
4. Anotar qué respalda una fuente y cuáles son sus límites.
5. Registrar contradicciones y el próximo paso para resolverlas.
6. Analizar actores y vínculos solo cuando exista una base pública documentable.

El sistema es para investigación cívica y análisis descriptivo. No convierte rumores en hechos, no calcula quién ganará una elección y no clasifica candidatos como mejores o peores. Las interpretaciones deben distinguirse de los datos y poder rastrearse hasta sus fuentes.

## Acceso y privacidad

Se conserva el acceso visual existente. **No es una barrera de seguridad real**: el código está en un repositorio público y la validación de clave ocurre en el navegador. Los datos se guardan en el almacenamiento local del navegador y no se sincronizan entre dispositivos.

No cargar información confidencial, datos personales sensibles ni material obtenido sin autorización. Para un centro realmente privado se necesitará autenticación y almacenamiento protegidos del lado del servidor.

## Uso y respaldo

- La aplicación estática funciona en el navegador.
- Exportá copias JSON con regularidad; una copia puede incluir todos los registros.
- No hay publicación automática ni conexión a una base de datos.
- GitHub Pages: Settings → Pages → Deploy from a branch → rama `main` y carpeta `/(root)`. Esperar a que GitHub confirme la URL de publicación.

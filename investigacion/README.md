## Método

- Cada afirmación debe distinguirse como **documento oficial**, **dato periodístico atribuido**, **declaración**, **hipótesis analítica**, **percepción social** o **dato pendiente**.
- Cada registro debe tener fecha, enlace, autor/emisor y estado de verificación.
- Las notas periodísticas sirven para detectar temas y pistas; las conclusiones jurídicas, presupuestarias o de ejecución necesitan documentos primarios.
- No se inventan índices de aprobación ni “temperatura social” representativa a partir de pocas entrevistas.
- Se documentan actos públicos, decisiones y relaciones políticas públicas verificables; no se registran datos privados ni rumores personales como hechos.
- La visualización futura debe expresar también vacíos, desacuerdos y nivel de confianza.

## Estado

Los documentos iniciales son una **base de investigación**, no una auditoría exhaustiva ni una determinación jurídica. Las fuentes y los casos deben actualizarse cuando aparezcan actas, ordenanzas, decretos, expedientes o aclaraciones posteriores.
